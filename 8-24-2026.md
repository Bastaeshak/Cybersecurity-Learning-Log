# LetsDefend — Web Attack Detection

## Web Attacks Reviewed

Today I studied and practiced identifying several common web application attacks:

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Command Injection
- Insecure Direct Object Reference (IDOR)
- Local File Inclusion (LFI)
- Remote File Inclusion (RFI)
- Open Redirection
- Directory Traversal
- XML External Entity (XXE)
- Brute-Force attacks

### Detection Techniques Practiced

I practiced analyzing:

- HTTP request methods
- Request URLs and parameters
- POST request bodies
- HTTP response codes
- HTTP response sizes
- Source and destination IP addresses
- User-Agent strings
- Encoded/decoded URLs
- Repeated request patterns
- Web server logs
- Firewall logs

One important lesson was that an HTTP `200` response alone does not always prove exploitation was successful. Response content, response size, endpoint activity, and other evidence must also be considered.
