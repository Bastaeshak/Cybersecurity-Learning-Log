## What I Worked On

Today I continued the **SOC Analyst Learning Path** and focused on identifying, investigating, and responding to web application attacks.

### SQL Injection (SQLi)

- Analyzed HTTP requests for SQL injection indicators.
- Identified payloads containing:
  - `AND 1=1`
  - `UNION ALL SELECT`
  - `information_schema.tables`
- Practiced URL decoding to expose encoded attack payloads.
- Used HTTP status codes and response sizes during analysis.
- Investigated source IP reputation using VirusTotal and AbuseIPDB.
- Learned the difference between a malicious request being processed and confirming the attacker's full objective was achieved.

### Cross-Site Scripting (XSS)

- Studied the three main XSS types:
  - Reflected XSS
  - Stored XSS
  - DOM-Based XSS
- Identified XSS indicators such as:
  - `<script>`
  - `alert()`
  - `javascript`
- Investigated an XSS SOC alert from initial detection through escalation.
- Correlated HTTP activity with endpoint, browser, terminal, and network telemetry.
- Learned that seeing an XSS payload does not automatically prove JavaScript successfully executed.

### Command Injection

- Learned how unsanitized web input can lead to operating-system command execution.
- Identified commands including:
  - `ls`
  - `whoami`
  - `uname`
  - `cat /etc/passwd`
  - `cat /etc/shadow`
- Investigated a **successful command injection attack**.
- Correlated the malicious HTTP requests with endpoint terminal and process activity.
- Confirmed command execution based on matching endpoint activity around the alert timeframe.
- Practiced making a containment decision after confirming host-level execution.
- Investigated a second command injection alert that turned out to be a **False Positive**.
- Determined the detection rule matched `ls` inside the legitimate search term `skills`.
