## Linux for Blue Team / CySA+ Study

Continued Linux command-line training with a focus on skills useful for SOC analysts.

### Linux Filesystem

Reviewed important Linux directories and their security relevance, including:

* `/var` – logs and changing system data
* `/etc` – system configuration
* `/home` – normal user files
* `/root` – root user's home directory
* `/tmp` – temporary files and a potential location for attacker tools
* `/proc` – running process/system information
* `/dev` – device files
* `/boot` – boot and kernel-related files
* `/opt` – optional/additional software
* `/media` and `/mnt` – mounted storage
* `/bin` and `/sbin` – executable and administrative binaries

### Linux Terminal Commands

Practiced:

* `pwd` – display current working directory
* `cd` – change directories
* `ls` – list files/directories
* `ls -a` – include hidden files
* `ls -l` – detailed file listing
* `ls -la` – detailed listing including hidden files
* `touch` – create an empty file
* `mkdir` – create directories
* `mkdir -p` – create nested directory structures
* `whatis`, `help`, and `man` – retrieve command documentation

Also reviewed Linux path navigation:

* `/path` – absolute path
* `.` – current directory
* `..` – parent directory
* `~` – user's home directory
* `-` – previously visited directory

I completed multiple scenario-based quizzes to reinforce these Linux concepts and identify areas that need additional review.
